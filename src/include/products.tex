\begin{itemize}
    \item \textbf{Funnel} --- A toolkit for distributed task execution built around the GA4GH Task Execution Schema (TES), a standard API for describing and running batch tasks across cloud and HPC backends. Lead developer; used in production to orchestrate genomic analysis pipelines at OHSU.

    \item \textbf{py-tes} --- A Python client library for the GA4GH Task Execution Schema (TES), giving researchers and pipeline developers a simple interface for submitting and monitoring tasks on any TES-compliant execution backend.

    \item \textbf{nf-ga4gh} --- A Nextflow plugin integrating the GA4GH Task Execution API, allowing existing Nextflow genomic workflows to run against multiple cloud and HPC execution backends without rewriting pipeline code.

    \item \textbf{DRS Downloader} --- A data transfer tool implementing the GA4GH Data Repository Service (DRS) standard, enabling cross-platform data retrieval between cloud storage systems and local research environments.

    \item \textbf{FHIR-Aggregator Client} --- An HL7 FHIR client for the NIH Cloud Platform Interoperability program, using GraphDefinition-driven traversals to query and locally analyze interconnected clinical and genomic data hosted on Google's Cloud Healthcare API. Lead developer.
\end{itemize}
