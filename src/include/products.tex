\begin{itemize}
    \item \textbf{Funnel} --- A toolkit for distributed task execution built around the GA4GH Task Execution Schema (TES), a standard API for describing and running batch tasks across cloud and HPC backends. Lead developer; used in production to orchestrate genomic analysis pipelines at OHSU.

    \item \textbf{CALYPR Status Monitor} --- A real-time monitoring dashboard tracking the health and availability of OHSU's CALYPR data commons services.

    \item \textbf{Backup Service} --- An automated backup and restore system for genomic data and metadata, built to support compliance and disaster-recovery requirements for cloud-hosted research data.

    \item \textbf{DRS Downloader} --- A data transfer tool implementing the GA4GH Data Repository Service (DRS) standard, enabling cross-platform data retrieval between cloud storage systems and local research environments.

    \item \textbf{RemoveMyWaste} --- A map-based application, developed in Java with a MariaDB/MySQL backend, for locating hazardous waste disposal centers. Personally developed the Android application and web interface and set up hosting for the web and database components.
\end{itemize}
