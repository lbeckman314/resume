\paragraph{EXPERIENCE}\

\vspace*{\baselineskip}

As a Research Software Engineer at the OHSU Knight Cancer Institute, I have directly addressed the technical challenges central to this role --- in previous positions I have:

\begin{itemize}

\item Architected and led development of a cloud-native workflow orchestration system spanning \textbf{AWS, Azure, GCP, and OpenStack}, implementing Lambda-style event-driven data processing pipelines for structured and unstructured genomic data at scale

\item Designed and built data pipelines integrating \textbf{BigQuery} and cloud data warehouse infrastructure through the \link{https://calypr.org}{CALYPR} platform, supporting cross-institutional cancer research data sharing

\item Implemented \textbf{DevSecOps} practices end-to-end: automated CI/CD pipelines, infrastructure-as-code with Terraform and \link{https://github.com/ohsu-comp-bio/helm-charts}{Helm/Kubernetes}, compliance workflows, and backup/restore procedures for regulated genomic data

\item Built distributed task execution infrastructure using the \link{https://www.ga4gh.org/task-execution-services/}{GA4GH TES API} (published in \link{https://ieeexplore.ieee.org/abstract/document/10564576}{IEEE CiSE 2024}), enabling portable workload execution across heterogeneous cloud and HPC environments --- analogous to Databricks/Snowflake cross-platform federation

\item Designed and deployed \textbf{agentic AI workflows} using \link{https://www.anthropic.com/claude}{Claude}, \link{https://ollama.com/}{Ollama}, and the \link{https://modelcontextprotocol.io/}{Model Context Protocol (MCP)}, including prompt engineering, fine-tuning with \link{https://unsloth.ai/}{Unsloth}, and RAG architecture prototyping

\item Contributed open-source tooling to \link{https://github.com/uc-cdis/gen3-workflow}{Gen3-Workflow}, \link{https://github.com/nextflow-io/nf-ga4gh}{nf-ga4gh}, and the \link{https://github.com/anvilproject/drs_downloader}{DRS Downloader}, broadening cross-cloud data access across NIH AnVIL, Terra, and BioData Catalyst

\end{itemize}
